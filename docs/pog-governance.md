# POG 治理：全公司怎么管、复用、审计这些资产

POG 回答的是组织层面的问题：Prompt 不再是个人聊天记录，而是团队资产。

## 最小治理清单

- **目录**：`prompts/` 一个构件一个文件，命名用动词+对象，例如 `code-review`。
- **版本**：语义化版本，改输出格式升大版本，改措辞升小版本。
- **负责人**：每个构件写负责人和最后评审日期。
- **复用**：写清适用场景、不适用场景、依赖的模型与工具。
- **审计**：每次发布记录改了什么、评估分数、回归结果；高风险场景保留人工复核。
- **权限**：涉及内部数据、密钥、客户信息的 Prompt，单独标注，不进公开案例库。

## 从个人到团队的演进

1. 个人：一个 Prompt + 一套测试用例，能稳定复用。
2. 小组：统一命名和版本，评审后入库，别人可以直接复用。
3. 公司：目录 + 审计 + 权限，Prompt 资产和代码资产同等管理。
