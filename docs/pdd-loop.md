# PDD 循环：意图 → 生成 → 评估 → 迭代

PDD 回答的是“开发循环快不快”，PDE 回答的是“这个 Prompt 本身质量够不够”。
两者配合：用 PDD 的循环速度，去打磨 PDE 的构件质量。

## 一轮怎么做

1. **意图**：一句话写清这次要解决什么、给谁用、成功标准是什么。
2. **生成**：按结构模板写一版 Prompt，跑 3–5 条代表性用例。
3. **评估**：按 `eval/` 里的评分标准打分，记录失败模式（格式错、定位错、建议不可执行、编造信息）。
4. **迭代**：一次只改一个变量（例如只改输出 Schema，或只改约束），再跑回归。
5. **入库**：分数达标且回归通过后，按 POG 规范写版本和变更记录。
