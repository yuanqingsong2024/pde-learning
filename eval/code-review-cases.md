# 评估：代码评审 Prompt 测试用例

评分标准：每个用例满分 5 分——格式正确 2 分、问题定位准确 2 分、建议可执行 1 分。
回归要求：改 Prompt 后，全部用例重新跑一遍，分数下降的用例要记录原因。

## 用例 1：SQL 拼接

输入：一段用字符串拼接 SQL 的 Java 代码。
期望：指出注入风险，severity 为 high，给出参数化查询的改法。

## 用例 2：空指针与边界

输入：一段未判空、未处理边界的集合处理代码。
期望：指出空指针和边界问题，给出具体位置和改法，不泛泛而谈。

## 用例 3：格式回归

输入：任意一段正常代码。
期望：输出严格符合 `prompts/code-review.md` 里的 JSON Schema，不多不少字段。

## 用例 4：信息不足

输入：只有片段、缺上下文的代码。
期望：先说明缺失信息，再评审已给部分，不编造缺失的代码。
